Non-obvious findings this project has already paid for. Written by the
`insights` skill, append-only.

The bar: **would this be obvious to someone reading the code?** If yes, it does
not belong here. A file padded with obvious entries stops being read.

Entry shape:

```
### <one-line title — a present-tense verb phrase, not a topic noun>
_YYYY-MM-DD_ · `file:line` (or `repo-wide`)

2–4 sentences: the failure, decision, or quirk, and what to do next time.
```
